# 客戶價值中心 架構規劃

新合達不動產客戶價值中心：以客戶價值週期（來人、成交、工程期、客變、驗屋、點交、售後、住戶再行銷）為骨架，把現有產品接進 CDP，統一 LINE 入口，並以受眾輪廓與外部數據夥伴合作找新客。
